## Доклад «Агенты работают, даже когда я сплю»

Если есть бэклог или есть что улучшать — в том числе по секьюрити.

Для заказчиков я делаю AI-агентов для внутренних продуктов, которые нельзя показать: наружу выходят только анонсы в прессе. После работы — то, что можно: две браузерные 3D-игры, одна VM и 436 релизов в открытом git log. Без цели заработать: ни магазинов, ни рекламы, ни монетизации. И с нарочно урезанным бюджетом: подписка Claude за $20 и $100 на OpenRouter, чтобы понять, для каких задач хватает effort medium, а где без x-high никак.

Расскажу, как на трёх проектах поднимался по лестнице зрелости AI-разработки. Race the City — гонки по любому городу мира, собранному на лету из OpenStreetMap, без единого сервера: 164 релиза за три дня и треть коммитов ночью, потому что узким местом был я. claude-remote-vm-dev — сессии Claude Code на VM, которые работают, пока ноутбук закрыт. itffm — грибной лес по реальному месту, где семь агентов параллельно разобрали пачку баг-репортов меньше чем за час.

Покажу, что давать агентам на ночь: бэклог и секьюрити — девять уязвимостей, две из них критические, закрыты одним коммитом. Разберу, где агенты раз за разом ошибаются и что ловит то, что пропускают зелёные тесты. И отдельно объясню, почему статический сайт на открытых данных без бэкенда хорош сам по себе, без всяких агентов. Приходите, если хотите увидеть, как выглядит AI-разработка, когда агентов больше одного.
